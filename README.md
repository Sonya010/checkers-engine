## Що реалізовано в проєкті

Бібліотека та консольний застосунок (CLI) для гри в шашки з розділеною чотиришаровою архітектурою:

1. **Шар правил (`src/rules/`)**:
   - Параметризована конфігурація правил (`Rules`), що підтримує різні варіанти гри без дублювання логіки генератора.
   - Реалізовані варіанти: **Українські шашки (8×8)** та **Англійські шашки / Checkers (8×8)**.
   - Передрахована геометрія темних клітинок, діагональних сусідів і променів (`BoardGeometry`).
   - Повний генератор легальних ходів (`MoveGenerator`): обов'язкове взяття, взяття вперед і назад, багатоходові серії, правило «турецького удару» (збиті шашки не знімаються до кінця ходу й блокують шлях), летючі дамки з обов'язковим вибором поля з продовженням бою, перетворення в дамку під час серії (`continue-as-king`, `ends-move`).
   - Незмінний стан позиції (`Position`) із 64-бітним Zobrist-хешуванням (`key`), визначенням перемоги та нічиї за лімітом ходів дамок і ендшпільними співвідношеннями.
   - Клас `Game` з історією ходів та автоматичною фіксацією нічиї за 3-кратним повторенням позиції.

2. **Шар нотації (`src/notation/`)**:
   - Підтримка алгебраїчної (`a1`–`h8`) та числової (`1`–`32`) нотації клітинок.
   - Парсинг і форматування тихих ходів (`c3-d4`, `11-15`) та серій взяття (`a3:c5:e7`, `21x14x7`), включно зі скороченим записом.
   - Повний цикл роботи з форматом **PDN (Portable Draughts Notation)**: токенізатор, парсер заголовків і ходів (`parsePdn`), валідація партій (`replayPdn`) та експорт у PDN (`formatPdn`).

3. **Шар пошуку та ботів (`src/search/`)**:
   - Працює виключно через публічний інтерфейс `Position`, не знаючи про внутрішнє представлення дошки.
   - Евристична оцінка позиції (`evaluatePosition`): матеріал (шашка = 100, дамка = 300), просування вперед, контроль центру, захист дамочного ряду, бонус темпу.
   - `RandomBot` — детермінований бот на основі псевдовипадкового генератора із фіксованим `seed`.
   - `MinimaxBot` — бот на алгоритмі Negamax / Minimax з **Alpha-Beta відсіканням**, **упорядкуванням ходів** (`move-ordering`) та **таблицею транспозицій** (`TranspositionTable`) на Zobrist-ключах.

4. **Консольний інтерфейс (`src/cli/`)**:
   - Інтерактивна гра в терміналі (`play`), автоматичні матчі між ботами (`botmatch`) та покрокове відтворення збережених PDN-партій (`replay`).

## Відображення дошки та позначення символів

Під час запуску гри в терміналі виводиться дошка 8×8 з координатами (`a`–`h` та `1`–`8`):

```text
    a b c d e f g h
  +-----------------+
 8|   b   b   b   b | 8
 7| b   b   b   b   | 7
 6|   b   b   b   b | 6
 5| .   .   .   .   | 5
 4|   .   .   .   . | 4
 3| w   w   w   w   | 3
 2|   w   w   w   w | 2
 1| w   w   w   w   | 1
  +-----------------+
    a b c d e f g h
Rules: ukrainian | Turn: white
Legal moves (7): a3-b4, c3-b4, c3-d4, e3-d4, e3-f4, g3-f4, g3-h4
```

### Що означають символи на дошці:
- `w` — проста біла шашка (man);
- `W` — біла дамка (king);
- `b` — проста чорна шашка (man);
- `B` — чорна дамка (king);
- `.` — вільна темна (ігрова) клітинка;
- ` ` *(пробіл)* — світла (неігрова) клітинка.

### Як записуються ходи:
- **Українські шашки (`--rules ukrainian`)**:
  - Тихий хід записується через дефіс `-`: наприклад, `c3-d4`.
  - Взяття записується через двокрапку `:`: наприклад, `c3:e5` або серія `a3:c5:e7`.
- **Англійські шашки (`--rules english`)**:
  - Використовуються номери темних клітинок від `1` до `32`.
  - Тихий хід — через `-` (наприклад, `11-15`), взяття — через `x` (наприклад, `22x15`).
- Під дошкою завжди виводиться рядок `Legal moves (...)` з усіма доступними за правилами ходами у поточній позиції.
- Для виходу з інтерактивної гри введи `quit`.

## Режими роботи та як їх запускати

### 1. Інтерактивна гра (`play`)

**Грати за білих проти розумного бота Minimax (глибина 4):**
```bash
npm start -- play --rules ukrainian --white human --black minimax:4
```

**Грати за чорних проти бота Minimax:**
```bash
npm start -- play --rules ukrainian --white minimax:4 --black human
```

**Грати проти випадкового (слабкого) бота:**
```bash
npm start -- play --rules ukrainian --white human --black random
```

**Грати самій за обидві сторони (людина проти людини):**
```bash
npm start -- play --rules ukrainian --white human --black human
```

**Грати в англійські шашки (першими ходять чорні):**
```bash
npm start -- play --rules english --black human --white minimax:4
```

---

### 2. Автоматичний матч «Бот проти Бота» (`botmatch`)

Запускає повну партію між двома ботами із заданим `seed` і в кінці виводить фінальну дошку, результат та згенерований запис партії у форматі PDN:

```bash
npm start -- botmatch --rules ukrainian --white minimax:3 --black random --seed 42
```

Матч в англійські шашки:
```bash
npm start -- botmatch --rules english --white random --black minimax:3 --seed 10
```

---

### 3. Відтворення партії з PDN-файлу (`replay`)

Відтворює партію з файлу крок за кроком і перевіряє кожен хід на легальність:

```bash
printf '[Event "Sample Game"]\n[Rules "ukrainian"]\n\n1. c3-d4 b6-a5 2. d4-c5 d6:b4 3. a3:c5 *\n' > /tmp/sample.pdn
npm start -- replay /tmp/sample.pdn
```

## Як порахувати кількість рядків коду (LOC)

### Через утиліту `cloc`

Порахувати чистий код ядра (`rules`, `notation`, `search`):
```bash
npx cloc src/rules src/notation src/search
```

Порахувати весь код у `src/` (разом із CLI):
```bash
npx cloc src
```

Порахувати весь проєкт разом із тестами (`src/` + `tests/`):
```bash
npx cloc src tests
```
